# Contexto académico

Este repositorio se desarrolló como entregable de la Maestría en Arquitectura de Software del Politécnico Grancolombiano, en el módulo Construcción de Software con Tecnología Cloud:

- **Unidad 2** — "Diseño Arquitectónico y Aprovisionamiento de Infraestructura Cloud como Código": arquitectura hub-spoke base (`envs/`, módulos `networking`, `security-keyvault`, `data-sql`, `compute-appservice`, `observability`).
- **Unidad 3** — componentes serverless y arquitectura orientada a eventos: flujo de confirmación y notificación de pagos (módulos `messaging-servicebus`, `compute-serverless`, `api-management`, más `sql/002_notificaciones_transaccionales.sql`).

Autoría: Grupo 2. Sección de Infraestructura como Código y Seguridad y Gobierno: Giovanny Plazas Lozano.

El resto de la documentación de este repositorio (`README.md` y los `README.md` de cada módulo) describe la infraestructura en sí, sin referencia a esta procedencia académica.
